## Arquivos
Cada `.dc.html` é uma prancha do canvas (HTML autocontido; abre no navegador, mas o layout final é o do canvas).
- `Main.dc.html`: identidade (logo, cor, tipografia)
- `Perfil.dc.html`: perfil @perissima (390×844)
- `Rotulo.dc.html`: pote do MVP
- `Post-manchete.dc.html`: post 1, "Você não está cansada dos seus filhos."
- `Post-isso-e-peri.dc.html`: post 2, capa do carrossel "isso é peri"
- `Post-copo.dc.html`: post 3, "um copo por dia."
- `canvas.json`: a disposição das pranchas no canvas

Onde está escrito `[foto: …]` entra fotografia; nenhuma imagem foi gerada.
